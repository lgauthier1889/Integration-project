# Integration Project

This project is a **C++ application** designed to calculate **loan functionalities** for a car sales program. It helps users by providing calculations for car payments, managing discounts, and applying loan details. The project includes functions for calculating **taxes**, **fees**, and the **monthly payment** for car loans.

## Features
- **Sales Price Calculation**: Calculates taxes, fees, and unpaid balance.
- **Loan Calculation**: Supports monthly payments and interest calculations.
- **User Input**: Accepts user input for car price, loan amount, and more.
