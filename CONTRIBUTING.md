## Contributing to Integration Project

Thank you for your interest in contributing! Here's how you can help:

### How to Contribute:
- **Report Issues**: Use the GitHub [Issues tab](https://github.com/lgauthier1889/Integration-project/issues) to report bugs, request new features, or suggest improvements.
- **Submit Pull Requests**:  
  - Fork the repository.
  - Create a new branch for your changes.
  - Implement your changes and test them.
  - Submit a **Pull Request** (PR) to the `main` branch. Ensure your PR description explains the purpose of the changes.
  
### Code Standards:
- Follow the **C++ coding style** used in the project. If you’re unsure, check out existing code for style references.
- We aim for **clean, readable code** with **meaningful commit messages**. Please write descriptive messages to explain what your change does.
  
### Reviewing PRs:
- After submitting your PR, the team will review it. We may ask for adjustments or improvements before merging
